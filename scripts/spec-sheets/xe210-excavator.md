# XE210 Hydraulic Excavator Specification

Document ID: SPEC-XE210
Machine type: crawler hydraulic excavator

## Power and weight

- Rated power: 129 kW
- Operating weight: 21.5 t
- Bucket capacity: 0.93 m3
- Maximum digging depth: 6.6 m
- Maximum digging reach: 9.9 m

## Work equipment

- Boom length: 5.7 m
- Stick length: 2.9 m
- Swing speed: 11.8 rpm
- Travel speed: 5.5 km/h (high) / 3.2 km/h (low)

## Hydraulic system

- Main pumps: dual variable piston pumps
- Maximum system pressure: 34.3 MPa
