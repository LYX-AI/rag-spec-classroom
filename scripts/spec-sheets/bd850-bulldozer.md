# BD850 Crawler Dozer Specification

Document ID: SPEC-BD850
Machine type: crawler dozer
Use: earthmoving, site leveling, short-distance pushing. This document is not for lifting work.

## Power and weight

- Rated power: 162 kW (220 hp)
- Engine: inline 6-cylinder diesel, water-cooled
- Operating weight: 18.9 t
- Ground pressure: 0.067 MPa

## Work equipment

- Blade type: straight-tilt blade
- Blade capacity: 4.3 m3
- Maximum drawbar pull: 170 kN
- Track gauge: 1880 mm

## Travel

- Forward gears: 3
- Reverse gears: 3
- Maximum forward speed: 11.2 km/h
- Fuel tank: 320 L

## Capabilities not listed

This specification does **not** include lifting capacity, rated hoist load, or boom length. BD850 is not a crane and must not be selected as lifting equipment.
